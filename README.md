## 💡 一、 專案發想初衷與背景故事 (Origin & Motivation)

### 1. 為人本教育痛點而生
本專案的發想源自於一個真實且迫切的生活場景：**我的媽媽是一位國中老師（同時兼任班級導師與科任教學）**。  
在國中教學現場，老師們每學期都必須給出學生的「平時成績」與「日常生活表現評語」。然而，傳統的教學現場往往面臨以下困境：
- **課堂手忙腳亂**：上課時一手拿粉筆/課本、一手拿平板或紙筆，若記點或點名流程超過 2 個步驟，在緊湊的 45 分鐘課堂中根本無法落實。
- **評分憑印象、缺乏客觀事證**：學期末結算平時分數時，往往只能憑模糊記憶打分，既難以客觀反映學生平時的努力，也難以向家長具體說明分數的由來。
- **親師晤談缺乏數據佐證**：遇到需要輔導關懷的學生時，老師手上缺乏時序紀錄，無法第一時間指出學生是「從何時開始成績下滑」或「在哪些常規上需要加強」。

### 2. 以 Vibe Coding 實現貼心客製化
為了真正解決媽媽在教育現場的痛點，我決定以 **Vibe Coding（自然語言引導 AI 編程）** 的方式，為她量身打造一款**兼具高效性、客觀量化與溫馨美感**的互動式班級經營 Web App。
- **溫馨三麗鷗風格（Hello Kitty 🌸）**：考量到國中教學壓力繁重，特別採用 Hello Kitty、小雙星、美樂蒂的溫暖粉嫩粉彩視覺與親切動效，希望能為媽媽在忙碌的備課與課堂經營中帶來好心情。
- **高度育成暗黑風格（COTE OAA 🏛️）**：在客製化過程中，為了滿足我個人的二次元熱情，額外打造了一套《歡迎來到實力至上主義教室》（高度育成高等學校）的高對比黑紅終端主題，具備學生實力綜合評級（OAA）與專屬動漫彩蛋，實現了一鍵無縫切換雙主題的雙重樂趣。

## 📋 二、 系統規格說明書 (System Specification)

### 1. 產品核心定位與目標客群
- **產品名稱**：ClassQuant Lite（課堂量化點記板與班級經營互動平台）
- **產品形態**：零建置（Zero-Build）之純前端單一 HTML 互動式 Web App（PWA 架構，支援 100% 離線執行）。
- **目標使用者**：國高中/國小班級導師、各科科任教師、補習班課堂管理者。
- **核心設計哲學**：
  1. **零滑動 1~2 秒極速交互**：手機介面 5 欄排列，全班 30~40 人座位一屏掌控，單擊即完成加扣分。
  2. **學業與品格雙軌量化**：學業均分（考試成績）與品格常規（加扣分點數）獨立計算，互不混淆。
  3. **資料 100% 本地隱私保障**：學生個資與分數僅儲存在瀏覽器本機端（LocalStorage），免伺服器無外洩風險。

---

### 2. 詳細功能模組規格矩陣

#### 【模組 1】課堂座位矩陣即時點記板 (`Matrix View`)
- **動態座位網格**：
  - 支援模擬教室真實座位佈局（預設 5 行 $\times$ 7 列，支援動態擴展至 45 人）。
  - 座位卡片實時展示：座號、學生姓名、性別標籤、當前累積點數、學業均分徽章。
- **最少路徑加扣分交互**：
  - **單選記點**：點擊單一座位卡片，立即浮現加扣分快捷選單；亦可直接點擊底部的常用快速標籤（如：`回答正確 +1`、`主動發問 +2`、`分心遲到 -1`），點擊後即刻觸發動態加分浮動氣泡與微震動反饋。
  - **群組批次記點**：支援「男生全選」、「女生全選」、「單號全選」、「雙號全選」及「全班全選」，方便分組競賽時整組批次獎勵。
- **隨機公平抽籤引擎**：
  - 具備語音抽籤與隨機跳動效果，抽中座號卡片高亮閃爍，杜絕課堂點名偏頗。

#### 【模組 2】班級名冊與 1 秒批次匯入管理器 (`Roster Manager`)
- **Excel 批次貼上自動解析器**：
  - 老師點擊「📋 1 秒批次貼上」，直接從學校 Excel 或 Word 複製「座號 姓名」文字並貼入彈窗文字框。
  - 內建智慧容錯正規表達式，自動去除多餘空白、頓號、流水號，自動分配座號並生成全班名冊。
- **班級雙軌制切換**：
  - 支援多班級管理，分為「導師班（本班）」與「科任班（任教班）」，資料庫互相獨立隔離。
- **名冊即時編修**：
  - 支援座號微調、學生姓名就地編輯（Inline Editing）、學生性別一鍵切換。

#### 【模組 3】事後回憶補記視圖 (`Retro Log View`)
- **課後批次追溯設計**：
  - 專門為「下課後才回想起來要登記加扣分」的真實情境設計。
  - 清單條列式展示全班座號，提供快速多選核取方塊。
- **常用評語範本套用**：
  - 內建多組課堂情境評語（作業缺交、打掃認真、同儕互助、課堂打瞌睡等），一鍵套用評語並自動帶入對應增減點數，批次寫入資料庫。

#### 【模組 4】統計戰情室與圖表分析 (`Dashboard & Analytics`)
- **EWMA 時序平滑趨勢圖 (Chart.js)**：
  - 運用指數加權移動平均（EWMA）演算法過濾短期單次小考雜訊，清晰呈現學生是「持續進步」還是「緩步下滑」。
- **學業 $\times$ 常規四象限分群散佈圖**：
  - X 軸為「品格常規點數」，Y 軸為「學業小考均分」。
  - 系統自動依班級平均數將學生劃分為四大群體：
    1. **拔尖進階組**（品學兼優）：提供加深加廣學習引導。
    2. **潛力未發揮組**（品行良好但學業卡關）：提供學業弱點補救教學。
    3. **努力待輔導組**（學業優良但常規散漫）：強化生活習慣與同儕互動。
    4. **高危機關懷組**（雙向低落）：優先啟動親師晤談與心理關懷。
- **五數綜合箱形圖 (Box Plot)**：
  - 即時呈現全班成績之中位數、四分位距（$IQR$）、最高最低分，精準掌握雙峰分化現象。

#### 【模組 5】學生個人檔案卡與晤談備忘 (`Student Dossier`)
- **全方位五維度雷達圖**：
  - 涵蓋「課堂參與」、「作業表現」、「生活常規」、「小考成績」、「進步幅度」五大構面。
- **歷史事件流水帳與撤銷 (Undo)**：
  - 條列該生所有被加扣分的詳細時間、事件名稱與分值，支援誤點時一鍵撤銷點數。
- **家長會談備忘錄一鍵複製**：
  - 系統自動整合客觀數據，生成標準化客觀分析文字，方便老師在親師座談或家庭聯絡簿中直接貼上。

#### 【模組 6】雙主題一鍵切換視覺系統 (`Dual Themes`)
- **三麗鷗粉嫩主題（Hello Kitty 🌸）**：
  - 櫻花粉（`#f43f5e`）、鵝黃與柔白搭配，搭載三麗鷗卡通吉祥物標章。
- **高度育成暗黑主題（COTE OAA 🏛️）**：
  - 高對比深邃灰黑（`#0a0a0c`）搭深紅金屬邊框，卡片呈現動漫角色實力 OAA 評級與震撼立繪剪影彩蛋。
- **全域無縫切換**：
  - 採用 CSS 變數（CSS Custom Properties）與 `data-theme` 根節點驅動，點擊頂部圖示 0.1 秒全站即時響應。

### 3. 技術架構規格 (Technical Stack)
1. **單一檔案整合（Single-File Architecture）**：
   - 全專案樣式（CSS）與業務邏輯（Vanilla JavaScript ES6+）100% 內嵌於單一 `index.html`。
   - 不依賴任何 Node.js、npm、Webpack 或 Vite，任何現代瀏覽器點擊即可離線執行。
2. **輕量外部 CDN 庫**：
   - **Tailwind CSS (CDN)**：快速實現響應式 RWD 佈局。
   - **Chart.js (CDN) + Boxplot 擴充**：渲染高效能 Canvas 向量互動圖表。
   - **Lucide Icons (CDN)**：現代化向量圖示。
3. **離線優先與資料持久化 (Offline-First)**：
   - 瀏覽器 `LocalStorage`：所有班級名單、點記紀錄、客製標籤秒級自動存檔。
   - PWA Service Worker：自動快取離線資源，即使在無網路的教室或地下室也能順暢開啟。

## 🤖 三、 Vibe Coding 提示詞討論與 AI 反覆迭代歷程

本專案完全透過自然語言提示詞與 AI 反覆對話、除錯與演進，真實迭代歷程如下：

### 階段一：人機對話釐清需求與討論規格
- **人類提示詞**：「我想要幫我當國中老師的媽媽寫一個課堂記點網頁，她需要能點名、加扣分、算平時成績。但她一手要拿粉筆，操作不能太複雜，你能幫我規劃系統規格嗎？」
- **AI 建議與規格收斂**：
  - AI 建議採用「模擬教室座位矩陣」取代傳統長條清單，並提出「單擊極速記點」概念。
  - AI 建議將「小考成績」與「常規點數」拆分為雙軌獨立指標，避免把生活常規與學業混為一談。
  - 敲定使用純原生 HTML5/JS + LocalStorage 離線存儲架構，避免伺服器維護與個資問題。

### 階段二：初版原型實作與痛點優化（多輪迭代）
- **迭代 1（名冊匯入體驗）**：
  - *問題*：媽媽手動一個個輸入 35 名學生名字太耗時。
  - *Vibe Coding 修正*：向 AI 提出「請設計一個容錯正規表達式，只要複製學校 Excel 的兩欄，貼上就能一秒自動拆解座號與姓名」，成功實現 1 秒批次匯入。
- **迭代 2（行動端版面防擠壓與字體縮放）**：
  - *問題*：在手機或投影機大字體設定下，座位卡文字會換行重疊被遮蔽。
  - *Vibe Coding 修正*：與 AI 協同設計 `--app-font-scale` 彈性字體縮放機制，並使用 CSS `clamp()` 與 `flex-shrink: 0` 確保所有重要按鈕與姓名永不截斷。
- **迭代 3（投影機暗黑模式高對比度調校）**：
  - *問題*：切換到 COTE 暗黑主題時，教室老舊投影機對比度不足，扣分紅色文字看不清。
  - *Vibe Coding 修正*：重新定義語意化三級色彩規範（翡翠綠 `+`、高對比玫瑰紅 `-`、岩石藍 `0`），大幅提升可讀性。
- **迭代 4（單一 index.html 檔案收斂）**：
  - *問題*：作業嚴格規定整理成單一 `index.html` 檔案，需將多個獨立 CSS 與 JS 檔案整合成單檔。
  - *Vibe Coding 修正*：透過字串重構腳本，將所有 CSS 與 JS 無損編譯內嵌至 `index.html`，並修正正則轉義問題，成功交付零依賴單檔版本！
